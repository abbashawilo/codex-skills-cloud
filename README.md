# Codex Skills Cloud

Public, versioned collection of third-party AI Skills and reference metadata for Codex Cloud.

- Registered Skills: `.agents/skills/`
- Source inventory: `SOURCES.md`
- Skill catalog: `SKILLS_CATALOG.md`
- Update metadata: `skills-manifest.json`
- Non-Skill resources: `resources/`

This repository stores source files only. It does not install dependencies, activate integrations, run third-party code, or contain credentials.

Current inventory: 41 source repositories and 577 registered Skill definitions (11 day-trading Skills added 2026-11-05; no runtime verification). New additions are incremental and source-qualified; existing Skills are preserved.
